The Dose-Window Hypothesis

Order, calibration, and externalised knowledge in small language models — a hypothesis with measured corollaries

Chad St Thomas · CuriousGene / Tablinum

Substrate: Qwen3-0.6B · LFM2.5-1.2B · Qwen3.5-2B · Nanbeige-4.2-3B · LFM2.5-8B-A1B Compute: one 6 GB laptop GPU

Abstract

This paper proposes and partially tests the Dose-Window Hypothesis: for a model of size N and a behaviour B, there is an interval [W_install, W_harm] in effective training exposure — examples × epochs, measured against the model's existing format lock — below which B does not install, and above which it saturates into template memorisation and erodes complementary behaviours, nearest neighbours first. The hypothesis emerged from an eight-week program training small language models (0.3B–8B) to investigate — answer from evidence, challenge false premises, abstain when evidence is absent, cite what each claim rests on — on a single 6 GB laptop GPU, with every score produced by frozen, deterministic instruments and paired controls.

Four measured corollaries support it and stand independently of it. (1) Order beats ingredients: the same category data cost 0.081 mixed into a base mixture and gained 0.016 as an isolated pulse followed by a format re-lock, at identical compute. (2) The quantisation floor is calibration, not bits: two 2-bit builds of one model, identical in file size and bit width, scored 0.014 and 0.708. (3) Knowledge divides cleanly: a static, runtime-editable fact table supplies the content half — lifting premise correction 4–5× at zero training, with a single 8B reaching 0.959 on the bench and 0.90 on a blind holdout — while the polarity half remains the model's job and fails below roughly 2B regardless of what the table supplies. (4) Interfaces leak: giving the model a retrieval tool scored 0.510–0.633 against 0.939 for retrieving before inference, through three separable failure modes.

The hypothesis is stated with its untested predictions; section 7 gives the applications at scale and the open agenda, and section 9 states what remains unestablished. The evaluation harness and CLI are released as open source.

1Measurement infrastructure

Every score in this paper comes from a frozen instrument with a deterministic grader and a paired control. This section defines what that means, how answers are graded, and how the reported numbers are bounded.

1.1 What an instrument is

A question set with a deterministic grader, written and sealed before any training run and never trained on. Four disciplines apply: the file, its generator, and its build seed are committed together and never rebuilt in place; training corpora are checked for shared gold values against every frozen set; every item's gold target grades against itself at 1.0 by construction; and compared conditions share item identities exactly, so the comparison is paired.

Standing guard

shortcut_check runs on every new premise or entailment set before it is trusted. It fits simple baselines — length ratio, lexical overlap, answer position — and fails the set if any exceeds 0.90. Backfilled across eight frozen instruments, the values were 0.783–0.867.

1.2 Controls and contamination

Every condition reported in this paper is paired with its control on identical items — an uplift without its baseline is not a result. Training corpora are re-graded for instrument overlap before every run, and the office evaluation instruments are deliberately not published, because a published evaluation set becomes a training set.

1.3 The grader

The production grader is strictly additive across three stages: exact and substring gold-value matching under a rejection lexicon, with unit normalisation; the same test applied to a tail window of the raw answer; and an NLI entailment check with the gold fact as premise and the answer as hypothesis, requiring P(entail) ≥ 0.80. Calibration: 0.991 entailment on a tight paraphrase, 0.715 on a vague one, correctly declined. Tests pin the bar at exactly 0.8.

For paired comparisons on identical items, D_i = candidate_i − baseline_i in [−1, 1], and the radius doubles because the range width doubles.

Two further constraints on inference were measured. Identical prompt_sha256 produced only 3 of 30 byte-identical answers across server restarts, giving a ≈2-item noise band on n = 30 across server lifetimes; within-server comparisons are robust, absolute values are ±0.07. And scores are compared within a backend only, because kernel numerics can flip an argmax at the margin — cross-backend cells agree within ≤2 items, so curves are read within-sweep.

2The dose window

The order in which a behaviour is trained matters more than the data used to train it. Installing one behaviour by mixing its data into the base mixture cost score twice; applying the same data as an isolated pulse followed by a format re-lock produced the program's best result.

Dose-window hypothesis

For a model of size N and behaviour B, there exists an interval [W_install, W_harm] in effective exposure — examples × epochs, measured against the model's existing format lock — such that below W_install the behaviour does not install, and above W_harm it saturates into template memorisation and erodes complementary behaviours, nearest neighbours first.

Status of its predictions. P1, windows widen with scale: supported at one size pair (0.6B → 1.2B, same recipe), untested beyond. P2, damage is dose-driven rather than data-driven: supported (v19/v20 vs v21; swapped-order control collapsed to 0.497). P3, recovery asymmetry between formats and behaviours: confirmed (Table 2). The mechanism — gradient-level interference between category batches — is unmeasured; the correlation structure in Figure 3b is descriptive only. The hypothesis is therefore a hypothesis: two confirmed predictions, one partially confirmed, mechanism open.

2.6 Recipes are per-substrate

Three measured points on the same recipe family: at 0.6B the recipe trains behaviours up and MMLU rose 3.7 points; at 1.2B the same recipe preserves the cost but damages MMLU monotonically with dose (42.34 → 40.72); at Qwen3.5-2B the recipe regressed against a strong base across every variant measured (−0.08 overall, −5.22 MMLU). The dilution law is measured, not inferred. Recipe choice is an experimental variable per substrate, not a transferred constant.

3Compression: calibration, not bits

Two 2-bit builds of one model, identical in file size and bit width, scored 0.014 and 0.708. The variable was not how far the model was compressed but what the compressor was told to protect.

The mechanism is standard tooling, not an invention here. llama-imatrix runs a calibration corpus through the model and accumulates, per weight, an importance estimate derived from the expected squared activation flowing through it — the diagonal of an empirical Hessian/Fisher-type quantity. llama-quantize --imatrix then allocates bit precision by that importance: weights the calibration data exercises heavily keep resolution, weights it rarely touches are squeezed harder.

The contribution is the calibration corpus choice. The imatrix was built from this program's own corpora. A generic calibration set does not know which weights a given domain depends on. The consequence is practical: if a rung collapses, the first variable to fix is what you calibrated against, not the rung.

3.3 The parity ladder, and the IQ1 verdict

The deployable artifact is a matched pair (rung, table), and the product claim is a curve: composite score stays flat as weights shrink, with the table growing slightly to compensate. Pre-registered gates: at every rung there exists a table size scoring within 0.05 of the top-rung reference, and a larger table never hurts.

IQ1_M, calibrated from our own corpora, was measured on both architecture classes: dense 0.069, MoE 0.097. Both collapsed. The compression destroys the polarity capability itself, and the division of labour in §4 says the table cannot replace the model's reject half. IQ1 + engram parity with an uncompressed base fails on both classes; the ladder floor is calibrated 2-bit.

3.4 MoE quantisation armour

A 7.9B/A1.3B mixture-of-experts held 92–93% of its Q4 score at 2 bits, where the dense looped substrate measured 0.014–0.069. Expert redundancy functions as quantisation armour. This is one measured cell on one instrument, not a general claim about MoE architectures.

3.5 Tables are quantisation-immune

On one trained 1.2B substrate the same fact table scored 0.767 at F16 and 0.767 at Q4_K_M — bit-for-bit identical — and retained 70% of its uplift at Q2_K (0.533, against a 0.383 floor) at one fifth the file size. Facts in a table survive compression; facts in the weights do not.

Published numbers are not admissible references

A model advertised at ~84–85 MMLU scored 48.2 on this harness. The gap is protocol, not model: 0-shot letter-loglikelihood here against 5-shot generative on the full set, an offset of roughly 36 points that cannot be modelled away. Vendor benchmark numbers are inadmissible as base references on this harness; base-only runs of our own are the references, and a generation-based public bench is the cleaner external anchor.

4The engram: division of labour

An engram here is a static, runtime-editable fact table — a few hundred to a few thousand rows, each with source provenance — whose retrieved hits are injected into the prompt. No architecture change, no training. The task splits cleanly into a half only the model can supply and a half a table supplies better than training can.

4.1 The decomposition

Fine-grained grading separates three outcomes on reject-polarity items: corrected (rejected the premise and stated the true fact), affirmed (accepted a false premise), and rejected without content (rejected but could not state the fact). All arms share the same six retrieval misses, so the residual decomposes cleanly.

Polarity is the model's job. Accept or reject. At 0.6B, 50 of 60 reject items failed this way. Below roughly 2B the model affirms a false premise even when handed the true fact — a judgement limit, not a knowledge limit.

Content is the table's job. What the true fact is. Supply it and content failures nearly vanish; at 1.2B the model restates an injected fact 89% of the time when it rejects.

4.2 Uplift, and why its shape matters

Uplift is defined as the ratio of the engram condition to its paired control. The first true paired table in the program's history: 3.7× at 0.6B, 17× at 1.2B, 7.1× at 2B, 13× on the looped substrate at Q4, 5.1× and 4.7× on the two MoEs.

Uplift is non-monotone. It peaks mid-ladder and declines at the top as the control floor rises. The declining tail is the first measured support for the prediction that a substrate carrying knowledge natively has less headroom.

A related result: a gate that decides whether to supply the fact was falsified on both scales. Always-inject beats gated-inject, because injected facts help true-premise items too, and withholding costs more than the gate's reject decision adds.

4.3 Saturation arrives near a thousand facts

Growing a table from 310 to 3,000 facts bought +0.02 to +0.04 — a real gain, not a step change. Gate reads: within-class consistency passed (both MoEs trend identically), between-class difference passed (MoE saturates at 1,000, dense-2B still rising, 0.6B flat), and the capacity signature is supported but shallow. Anti-cheat guard: table growth uses generator-grown, provenance-recorded facts only, never bench-derived; golds stay frozen and hit@1 is re-measured at every size.

The three leaks are independent and they compound. Initiation: with the tool merely available, the 8B calls it on barely a third of items and answers blind the rest of the way. Query quality: with explicit framing the call rate reaches 98%, but the model's keyword queries hit the right fact only ~49% of the time. Round-trip conversion: even when the perfect fact is returned, conversion through the tool result is 0.722 against 1.000 for pre-injection.

The product reading

An MCP surface does not make a small model competent. At 350M the tool is called on 96–98% of items and conversion is still 0.27 with the perfect fact handed back — the misses are affirmed. The binding constraint at that scale is conversion, not access. For a bounded product scope, pre-injection is strictly better; tool-calling remains interesting only for open-ended retrieval the engram cannot anticipate.

The arithmetic wall

One-shot multi-row spreadsheet aggregation failed at every scale measured, including 1.2B with harness arithmetic supplied — asserting 102,000 against 15,834.36. Scale bought document quality, not the composition skill. The product answer is a deterministic harness that evaluates formulas against a harvested cell grid and prints exact totals regardless of model state. The measured boundary in the trained 350M: three rows 1.000, seven rows 0.167.

6The artifact

The deployable object is not a model. It is a triple: a table carrying the facts with per-row provenance, editable and versioned without retraining and bit-identical at every rung; a substrate carrying the judgement — accept, reject, abstain, cite — large enough for the polarity half; and a rung, a measured choice with a measured cliff, printed on the card next to the win.

Config rules are per-vertical because retrieval geometry is: topic-diverse corpora want a wide candidate pool with top-1 and no tiebreak; narrow corpora want a narrow pool with top-3, and measured worse at the wider setting. The optimisation question changes accordingly — not how small can the model be, but which half of the problem am I fixing.

7At scale, and where to go next

The measurements above were taken at 0.3B–8B on one 6 GB GPU. This section separates what they predict at scale from what remains open, and names the experiments the hypothesis most needs. Everything here is intended as open-source knowledge: the harness is released so each item can be run, checked, or falsified by someone else.

7.1 What the dose window predicts for large-model practice

If windows widen with scale — and P1 is confirmed at only one size pair — two consequences follow for fine-tuning at scale. First, targeted behavioural patching should become relatively cheaper as models grow: a pulse-then-re-lock curriculum sized against a damage ledger, rather than category data mixed into the base mixture. Second, multi-teacher consolidation should weight anchor replay by measured per-category damage — the DA-OPD anchor term, equation (3) — rather than uniformly. Both are extrapolations from the measured interval, not results.

7.2 What the calibration result changes at serving scale

Build the importance matrix from deployment-domain text, not a generic corpus, and ship quantisation rungs as measured pairs with their table. The measured rungs: calibrated 2-bit at parity with Q4 at 73% of the size on one dense substrate, and 92–93% retention at 2 bits on one MoE. If the MoE result holds across the class, 2-bit MoE serving is roughly a further 40% memory reduction at near-parity — the cheapest untested capacity lever in this paper.

7.3 What the division of labour changes about knowledge management

Perishable knowledge belongs in tables, not weights: per-vertical tables of roughly a thousand facts with per-row provenance, refreshed without retraining. The self-populating pipeline — search, distill a cited fact, answer — measured 0.800 against a 0.000 control on post-cutoff questions, at n = 5: a demonstration, not a result. Private enterprise knowledge is the axis on which external tables compose with rather than compete against large n-gram-table architectures: those tables freeze at pretraining; runtime-editable tables with provenance are structurally absent from them.

7.4 An open agenda

The experiments this hypothesis most needs, in the order a small team can run them:

  1. Scale test. The same pulse / re-lock pair at 7B–14B: two arms decide whether W_harm keeps widening.
  2. Mechanism test. Gradient cosine similarity between category batches during the pulse — the causal test the correlation matrix in Figure 3b cannot substitute for.
  3. Public replication. The calibration finding on a generation-based public bench, with the imatrix corpora published.
  4. Conflict-aware distillation. The named residual: two facts, same topic, different numbers — keep the document-pinned one.
  5. Multi-seed the headline cells and report paired intervals; several single-run cells here are point estimates.
  6. Instrument mirrors. Publish public versions of the frozen instruments — fresh items, same generators — so results are reproducible without contaminating the private sets.

8Method rules this program adopted

  1. Freeze instruments before training. A published evaluation set becomes a training set.
  2. Run a shortcut check on every new instrument. A trivial baseline above 0.90 means the instrument measures the shortcut.
  3. Pair every condition with a control. An uplift without a baseline is not a result.
  4. Report per-polarity. Reject and affirm are never blended.
  5. Structure-true testing. No pattern crosses an architecture class without its own cell; a cross-structure pattern may reflect the corpus rather than the architecture.
  6. A custom grader is a hypothesis until probed. Grade the grader.
  7. Read the generations, not the exit codes.
  8. Smoke gates check speed, not just completion. A gate that passed at 150 s/step implied a 47-hour run.
  9. Within-server comparisons are robust; absolute values across server restarts are not. Ship the comparison, annotate the absolute.
  10. State the failure mode next to the win.

9What remains unestablished

  • Production-scale quality assurance. Whether a ≥2B substrate with a fixed table clears 0.9 on genuinely real-world questions is predicted, not measured. The deciding cell has not run.
  • Below calibrated 2-bit. The cliff is measured on two architecture classes; whether some class has cheaper redundancy is untested.
  • Domain generality. One successful transfer on the model leg is a data point. The method's behaviour on a domain with different retrieval geometry is unknown.
  • Conflict. The named residual — two facts, same topic, different numbers — has no measured solution. Conflict-aware distillation is a proposal.
  • Cross-lineage anchoring. Same-initialisation self-anchoring is measured; anchoring a student to a different lineage's checkpoint is not.
  • The causal reading of the interference matrix. The correlation structure in Figure 3b is descriptive across eight sequentially selected runs. Gradient-level measurement is the named test and has not been run.
