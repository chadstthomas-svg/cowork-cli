The Dose-Window Hypothesis
Order, calibration, and externalised knowledge in small language models — a hypothesis with measured corollaries. Read the paper →
  • 01Order beats ingredients. The same training data cost 0.081 mixed in and gained 0.016 as a pulse followed by a re-lock, at identical compute.
  • 02Calibration, not bits. Two 2-bit builds of one model, identical in size and bit width, scored 0.014 and 0.708.
  • 03Knowledge divides cleanly. A runtime-editable fact table supplies the content half; judgment stays in the weights.
  • 04Interfaces leak. A retrieval tool scored 0.510–0.633 against 0.939 for retrieving before inference.

Quick start

pip install ".[office,engram]"

cowork --gguf cowork-companion-350M-Q8_0.gguf \
       --files budget.csv --compute \
       --instruction "What is the total travel spend for attendees with RSVP status Yes?"

Requires llama-server on PATH and a model rung — Q8_0 is the measured recommendation. The CLI computes arithmetic deterministically, constrains decoding to the envelope schema, and renders real .pptx/.xlsx/.docx artifacts.
